Hyper-local community platform

One primary community per user. Explore any community from Home.

My Community

MVP tech stack

  • Frontend: Next.js + TypeScript + Tailwind
  • Backend: Node.js (NestJS) + REST APIs
  • DB: PostgreSQL + Redis cache
  • Search: PostgreSQL FTS (MVP), OpenSearch (scale)
  • Storage: S3-compatible object storage

Core architecture

  • Auth + profile (primary community)
  • Community feed service (5 categories)
  • Messaging + inbox service
  • Notifications service (in-app + push + email)
  • Moderation service (reporting + spam checks)

Implementation Plan (MVP → Scale)

  1. Week 1-2: Auth, community model, tabbed feed, create/comment/ask flows.
  2. Week 3-4: Services directory + ratings/reviews + expiry jobs.
  3. Week 5: Inbox, notifications, unread counters, urgent visibility.
  4. Week 6: Moderation console, spam throttling, block/report tools.
  5. Future: Trust score, verified providers, payments, promoted listings.
